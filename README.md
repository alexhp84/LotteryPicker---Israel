# Lottery Picker (Israel)

A Flask/Python lottery number picker with an English/Hebrew interface. Number generation and validation are handled in Python on the server. JavaScript is used only for the language toggle and copying results.

## Run locally
```bash
pip install -r requirements.txt
python app.py
```

## Bonus numbers
Choose 0, 1, or 2 bonus numbers. Bonus numbers use the same range as the main numbers and cannot duplicate them.
